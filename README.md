# ExpenseFlow

**InternID:** CITS8288

## 📌 Project Overview

Expense Tracker Dashboard is a full-stack web application designed to help users manage, track, and analyze their personal expenses through a modern and interactive dashboard.

The application allows users to record transactions, organize expenses by category, view financial summaries, and analyze spending patterns through interactive charts.

## 🚀 Features

* 🔐 User authentication
* 💰 Add and manage expenses
* ✏️ Edit and delete transactions
* 📊 Interactive financial dashboard
* 📈 Expense and income visualizations
* 🗂️ Category-based expense tracking
* 💵 Total income and expense summaries
* 📱 Responsive and modern UI
* ⚙️ Settings section
* 🔄 Full-stack frontend and backend integration

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd Expense-Tracker-Dashboard
```

### 2. Backend Setup

```bash
cd backend
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the backend server:

```bash
uvicorn app.main:app --reload
```

### 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

The application will then be available through the local Vite development server.
